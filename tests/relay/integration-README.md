# Настоящий SSH-туннель и скачивание

Этот набор запускается **только в одноразовом контейнере**. Он создаёт локальный
sshd, временные SSH-ключи и тестового пользователя `relay` с заведомо публичным
тестовым паролем. К продовому адресу прокси он не подключается.

Из корня репозитория, Bash:

```bash
docker build -f tests/relay/integration.Dockerfile -t bitrix-relay-integration:test .
docker run --rm --init --env BITRIX_DISPOSABLE_TEST=1 \
  --mount "type=bind,source=$PWD,target=/repo,readonly" \
  bitrix-relay-integration:test
```

Нужен интернет для APK при сборке и для получения двух публичных файлов GitHub
во время проверки. Docker socket, порты хоста и каталоги прода не подключаются.

Проверяются настоящий пароль через управляющий PTY, уход SSH в фон, SOCKS с
удалённым DNS, сырой файл ключа GitHub и выпуск с перенаправлением на assets,
повторное использование одного подключения в соседних subshell, отказ при
неверном пароле, очистка при нормальном завершении и SIGTERM. Хеш скачанного
ключа сравнивается с закреплённым хешем установщика. Проверяется, что SSH не
удерживает канал результата, блокировку и вывод журнала после операции.

Единственная подмена транспорта — первый прямой curl возвращает ошибку 7.
При SOCKS вызывается настоящий curl. Функции берутся из текущего `install.sh`;
в тесте заменены только адрес на loopback и отпечаток на ключ тестового sshd.
Ограничения направлений, запрет shell и парольная аутентификация sshd сохранены.
Ограничение частоты неудачных подключений отключено только в тестовом sshd:
несколько отрицательных тестов используют один адрес loopback.
