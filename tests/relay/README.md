# Проверки подключения через GitHub relay

`test_transport.py` запускает настоящие функции из текущего `install.sh`,
извлекая их до границы CLI. Операции с пакетами, сайтами и службами не вызываются.
Подменены только внешние команды curl, SSH, ssh-keyscan, ssh-keygen и ss.
Интерактивные сценарии работают через настоящий управляющий терминал PTY;
пароль передаётся только после запроса, без передачи в аргументах или окружении.

Запуск из корня репозитория в одноразовом Linux-контейнере:

```bash
docker run --rm --network none \
  --mount "type=bind,source=$PWD,target=/repo,readonly" \
  python:3.11-slim \
  python -B /repo/tests/relay/test_transport.py /repo/install.sh
```

Набор проверяет:

- Прямое скачивание без SSH; подключение через relay после сетевого отказа
  или HTTP 403; отсутствие подключения при HTTP 404 и ошибке записи файла.
- Однократный запрос пароля и повторное использование соединения в соседних
  subshell-функциях настройки и скачивания.
- Поздний отказ прямого соединения внутри цикла чтения манифеста:
  стандартный ввод занят файлом, пароль всё равно читается из терминала.
- Удалённое разрешение DNS через SOCKS, отключение NO_PROXY для relay-запроса,
  отсутствие изменения глобальных переменных прокси и маршрутизации других сайтов.
- Отказ до передачи пароля при неправильном отпечатке или неудачном сканировании
  SSH-ключа; отсутствие интерактивного подключения без терминала и с --unattended.
- Неправильный пароль, отмену ввода, ошибку скачивания, Ctrl+C, TERM и HUP:
  соединение и временный каталог закрываются.
- Сохранность прежнего файла при пустом скачивании, публикацию завершённого файла,
  закрытие канала меню и дескриптора блокировки перед запуском SSH.

21 проверка прошла 2026-11-09. Начальный тест зафиксировал отсутствие
`with_download_context`; отдельный регрессионный тест воспроизвёл ошибочный
отказ подключения внутри цикла с перенаправленным stdin до исправления.

Эти проверки не доказывают доступность пользовательского прода: они намеренно
работают без сети. Реальное SSH-подключение и HTTPS-скачивание проверяются
отдельным интеграционным набором.
